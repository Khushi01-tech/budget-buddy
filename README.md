# FinTrackr 💰
A full-stack personal finance tracker built with React + Python Flask.

🔗 **Live site:** https://jazzy-sprinkles-9fbe09.netlify.app

## Features
- Track income & expenses in real time
- Set monthly budget limits with alerts
- Visualize spending with charts
- Dark professional dashboard UI

## Tech Stack
- **Frontend:** React, Recharts, Vite → Netlify
- **Backend:** Python Flask, SQLite → Render
